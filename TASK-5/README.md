
# Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The objective is to explore the dataset, clean the data, visualize important patterns, and identify the factors that influenced passenger survival.

# Tools & Libraries
Python
Pandas
Matplotlib
Seaborn
Jupyter Notebook

# Dataset
Titanic Dataset
Total Records: 891
Features: Passenger details such as Age, Sex, Passenger Class, Fare, Survival Status, etc.

# Analysis Performed
Data exploration using info(), describe(), and value_counts()
Missing value handling
Duplicate record check
Histograms for Age and Fare
Boxplots to identify outliers
Scatter plot to analyze Age vs Fare
Pairplot to explore feature relationships
Correlation heatmap
Relationship and trend analysis

# Key Findings
Most passengers were between 20 and 40 years old.
The majority of passengers traveled in Third Class.
Female passengers had a higher survival rate than male passengers.
First-class passengers were more likely to survive.
Passenger Class, Fare, and Sex showed the strongest relationship with survival.

# Conclusion

This project demonstrates the use of EDA techniques to understand data, identify trends, and extract meaningful insights through statistical analysis and visualizations.

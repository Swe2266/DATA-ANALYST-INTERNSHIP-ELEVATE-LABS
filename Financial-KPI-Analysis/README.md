# Financial KPI Analysis for a Startup 

**GRWTECH FINANCIAL KPI DASHBOARD**

## About the Project

This project focuses on understanding the financial performance of a startup using key business and customer metrics.

I worked with a simulated dataset for **GRWTECH**, a SaaS productivity platform for small businesses. The analysis covers the period from January to December 2025.

The main goal was to understand how revenue, expenses, customer acquisition and customer value changed during the year and what these numbers could tell us about the business.

## KPIs Covered

- Revenue
- Revenue Growth
- Net Burn
- Customer Acquisition Cost (CAC)
- Average Revenue Per User (ARPU)
- Customer Lifetime Value (LTV)
- LTV:CAC Ratio
- Run Rate
- Customer Growth
- Cohort Retention

## Tools Used

- **Excel** – Data organization and KPI calculations
- **Python** – Data cleaning, analysis and validation
- **Pandas** – Data manipulation
- **Matplotlib & Seaborn** – Data visualization
- **Tableau** – Dashboard and visual analysis

## Project Workflow

### 1. Data Preparation

The data was organized into different sheets for:

- Customers
- Revenue
- Expenses
- Marketing
- KPI calculations
- Cohort analysis

I cleaned and prepared the data before using it for analysis.

### 2. Financial Analysis

I calculated important startup metrics such as CAC, ARPU, LTV, LTV:CAC and burn rate.

For example:

**CAC**

Marketing Spend / New Customers

**LTV**

ARPU × Gross Margin / Monthly Churn

**LTV:CAC**

LTV / CAC

## Key Findings

A few important observations from the analysis were:

- Monthly revenue increased from **₹1.75 lakh in January to ₹35.5 lakh in December**.
- Active customers increased from **35 to 710** during the modeled period.
- CAC decreased from approximately **₹5,142.86 to ₹3,652.17**.
- The model moves from a monthly burn in the beginning of the year to an operating surplus from May onward.
- LTV is estimated at **₹1.25 lakh** based on the assumptions used in the model.
- LTV:CAC improved from **24.31x in January to 34.23x in December**.
- December run rate reached **₹4.26 crore**, based on December revenue multiplied by 12.

## Dashboard

The Tableau dashboard brings the main financial and customer metrics together in one place. It can be used to quickly compare revenue, expenses, customer growth and unit economics over the year.

## Important Note

The data used in this project is **simulated data created for learning and portfolio purposes**.

The customer-level data and monthly financial model are separate parts of the project, so the monthly figures should not be treated as a direct aggregation of the customer records.

The LTV calculation also uses assumed values for gross margin and monthly churn. In a real business analysis, these would be replaced with actual company data.

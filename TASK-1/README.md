Task 1: Data Cleaning and Preprocessing
# OBJECTIVE
To clean and preprocessed a sales dataset using Python and Pandas libraries for accurate and efficient data analysis.

#TOOLS USED
Python (pandas)
jupyter notebook

#TASK PERFORMED
Imported the sales dataset into Python.
Explored the dataset using Pandas.
Checked for missing values and duplicate records.
Verified data types of all columns.
Converted the `SALE_DATE` format to date-month-year format
Performed data cleaning.
Saved the cleaned dataset for further analysis.

### Files
- `sales_data.csv` – Original dataset
- `cleaned_sales_data.csv` – Cleaned dataset
- `Task1_Data_Cleaning.ipynb` – Jupyter Notebook containing the complete workflow

### Outcome
The dataset was successfully cleaned and prepared for further analysis and visualization.

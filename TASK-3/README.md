# PostgreSQL Internship Task 3

## OBJECTIVE
The objective of this project is to demonstrate the use of SQL queries in PostgreSQL for managing and analyzing an e-commerce database.

#DATABASE USED
Postgresql

#TABLES CREATED
1. Customs
2. Orders
3. Ecomm

#SQL QUERIES COVERED
SELECT
WHERE
ORDER BY
GROUP BY
Aggregate Functions (SUM, AVG)
INNER JOIN
LEFT JOIN
RIGHT JOIN
Subqueries
Views
Indexes
 
 #SAMPLE QUERIES PERFORMED
Display all customer records
Filter customers using WHERE
Sort records using ORDER BY
Group records using GROUP BY
Calculate SUM and AVG
Perform INNER, LEFT, and RIGHT JOIN
Create and execute Subqueries
Create Views for analysis
Create Indexes to optimize query performance

#CONCLUSION
This project demonstrates fundamental PostgreSQL operations, including data retrieval, data analysis, joins, subqueries, views, and indexing.
